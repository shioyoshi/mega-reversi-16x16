# 💪 PUMP HERO (パンプヒーロー) - 筋トレ・クリッカーRPG

ブラウザで遊べる本格筋トレ育成シミュレーションゲーム。
初期の身体データ（身長・体重・性別・運動歴）からリアルな基礎筋力と推定BIG3（ベンチプレス・スクワット・デッドリフト）を算出してスタート！
腕立て伏せ・腹筋・自重スクワットの基礎3種目から鍛え始め、自重発展種目を開放し、やがてジムに入会してバーベルベンチプレスやBIG3の極限重量へ挑もう！

## 🚀 特徴
- **リアルな筋力推定アルゴリズム**: 身長・体重・性別・年齢・運動歴からBMI、除脂肪体重(LBM)、初期推定1RMを算出。
- **自重トレからジムBIG3への開放ツリー**:
  - 自重初期: 腕立て伏せ、腹筋(クランチ)、自重スクワット
  - 自重発展: プランク、ディップス、斜め懸垂、チンニング、ブルガリアンスクワット、パイクプッシュアップ、ドラゴンフラッグ
  - ジム種目: ダンベルカール、バーベルベンチプレス、バーベルスクワット、デッドリフト、オーバーヘッドプレス、ラットプルダウン、レッグプレス
- **パンプ感 (PUMP) ＆ 超回復システム**: 連続トレーニングでパンプゲージが100%になると「✨ SUPER PUMP MODE (15秒間 獲得EXP 3倍 / 疲労ゼロ)」が発動！
- **アナトミー・マッスルマップ**: 人体シルエットの各部位（胸・背中・脚・体幹・腕・肩）が筋力レベルに応じて光り輝き、部位別の成長を可視化。
- **ニュートリション＆放置育成**: プロテイン、クレアチン、スマート筋電バンド、ジム仲間、トップトレーナー、自宅パワーラックなどで放置時も毎秒EXPを自動獲得。
- **Web Audio API によるダイナミックSE**: 金属プレートの挙上音やパンプ時の覚醒音をリアルタイム合成（外部音源通信なし）。
- **完全クライアントサイド動作**: データはブラウザの `localStorage` に自動保存され、オフラインでも軽快に動作します。
