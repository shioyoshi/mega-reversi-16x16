# ⚫⚪ 16×16 メガオセロ (MEGA REVERSI) - 特別ルール搭載

ブラウザで遊べる **16×16 (計256マス)** の新感覚巨大オセロ（リバーシ）ゲーム。
通常のオセロルールに加え、**「2×2の4マス区画（縦横1/8）」が同色で完成した時に発動する『メガブロック挟み込み反転』** 特別ルールを搭載！

## ⚡ 特別ルール: 2×2 メガブロック挟み込み反転
1. 盤面は縦横 1/8 ずつ区切られた **2×2 のブロック（計64区画）** で構成されています（太枠で表示）。
2. いずれかの 2×2 ブロック内の **4マスすべてが同じ色** で満たされると、そのブロックが「完成ブロック」となります。
3. 完成ブロックから縦・横・斜めの8方向にある敵ブロックを挟んで、その直線上に **同じ色の別の完成ブロック** が存在する場合、
   **その間にある相手の石が一気に自色へ大反転（メガリバーサル）！！**

## 🎮 機能一覧
- **CPU対戦**: 初心者向けの「かんたん」、戦略的な「ふつう」、角やメガブロックを狙う「つよい」の3段階AI。
- **2人対戦 (ローカル対人戦)**: 1台のPCやスマホで交代しながら対戦可能。
- **快適サポート**:
  - 打てる場所のハイライト（💡ヒントON/OFF）
  - 待った（↩️ 1手アンドゥ）機能
  - 自動パス判定・終局判定
  - Web Audio API による心地よい打音・裏返し音・メガ反転レーザー音
- **完全クライアントサイド動作**: サーバー通信なしで端末上で即座に動作。GitHub Pagesで公開中！
